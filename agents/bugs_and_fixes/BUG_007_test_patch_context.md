# BUG-007 — Несовпадение контекста патча тестов

Дата: 2026-10-26. Автор: Codex. Статус: РЕШЕНО.

## Симптом
apply_patch отклонил пакет обновления тестов: ожидался assert.equal для проверки статуса, тогда как текущий файл использовал assert.

## Причина
Лишняя строка контекста была указана не в точном виде. Пакет не применился, приложение не затронуто.

## Решение
Убрать ненужный контекст и обновить реальные строки файла. Повторный патч и 13 тестов прошли.

## Предотвращение
Для точечных патчей использовать минимальный подтвержденный контекст из текущего файла.
