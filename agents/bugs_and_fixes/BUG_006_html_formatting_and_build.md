# BUG-006 — Форматирование опубликованного HTML

Дата: 2026-10-26. Автор: Codex. Статус: РЕШЕНО.

## Симптом
git diff --check обнаружил пустую строку с пробелами в index.html:406. После удаления пробелов через Python на Windows build.mjs --check сообщил Generated HTML is stale. Первая попытка пакетного патча также остановилась: ожидаемая строка в active_task.md отсутствовала; изменения не применились.

## Причина
Удаление блока оставило пробелы. Python перезаписал документ с CRLF, тогда как генератор вставлял LF, поэтому проверка точного соответствия сгенерированных блоков корректно потребовала пересборку. Патч учета задачи опирался на несуществующий фрагмент.

## Решение
Пробелы удалены; generate нормализует документ к LF. Генератор исправлен отдельным патчем, учет задачи обновляется по актуальному содержимому; выполнена повторная сборка.

## Предотвращение
После изменения HTML/контента выполнять node build.mjs; генерируемый результат должен быть детерминированным и использовать единые окончания строк. Контекст патча сверять с текущим файлом.
