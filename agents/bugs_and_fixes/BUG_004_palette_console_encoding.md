# BUG-004 — Кодировка диагностического вывода

Дата: 2026-10-26. Статус: РЕШЕНО. Автор: Codex.

## Симптом
Одноразовая проверка эмодзи завершилась UnicodeEncodeError: charmap codec cannot encode character U+2630.

## Причина
Python stdout использовал CP1251; диагностический скрипт печатал Unicode-символы напрямую. Код приложения не затронут.

## Решение
Диагностика выводит JSON с ensure_ascii=True. Повторная проверка завершилась успешно.

## Предотвращение
Для технических отчетов о символах выводить ASCII escape либо явно задавать UTF-8.
