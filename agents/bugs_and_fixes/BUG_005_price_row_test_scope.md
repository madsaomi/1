# BUG-005 — Проверка строк прайса учитывала другую таблицу

Дата: 2026-10-26. Автор: Codex. Статус: РЕШЕНО.

## Симптом
node --test: AssertionError 9 !== 7 в проверке статической генерации прайса.

## Причина
Проверка считала все строки tr/th на странице, включая две строки структуры SAT, вместо только сгенерированного прайса. Генерация содержала правильные семь программ.

## Решение
Ограничить проверку маркерами PRICES_START/PRICES_END, сохранив проверку количества и идемпотентности сборки.

## Предотвращение
Проверять контракт конкретного компонента, а не похожую разметку всего документа.
