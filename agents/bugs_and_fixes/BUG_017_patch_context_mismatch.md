# BUG-017 — Неточное совпадение контекста документационного patch

Дата: 2026-10-27. Автор: Codex. Статус: ИСПРАВЛЕНО, PLAN-028.

## Симптом
Два вызова apply_patch отклонены: `Failed to find expected lines`. Первый использовал отдельный `#` вместо полной строки active_task; второй — сокращенный абзац README вместо фактической полной строки.

## Причина
Patch требует точного совпадения контекста. Несовпавший фрагмент отменяет весь составной patch до записи.

## Решение
Прочитаны фактические строки, операции разделены и повторены с полным контекстом. Проверено наличие плана, новой карточки задачи и актуального README. Код приложения этим сбоем не затрагивался.

## Предотвращение
Сначала читать редактируемый фрагмент; не включать неполные строки в контекст и не смешивать независимые изменения документации в один большой patch без необходимости.

## Дополнение PLAN-029
При подготовке aria-hidden для9плюсов assert по точному `<b>+</b>` не прошел:6тегов имеют переносы строк внутри. Запись не выполнялась. После чтения фактической разметки использован шаблон `<b>(\s*\+\s*)</b>` с проверкой9замен. Учитывать значимые различия строкового и структурного HTML-поиска.
