# 🐛 BUG-001: Блокировка кликов по странице невидимым оверлеем модального окна и specificity баги

**Статус:** Исправлен (Resolved)  
**Дата обнаружения:** 2026-10-24  
**Компонент:** UI / CSS / JS  
**Ответственный:** Antigravity (Gemini)  

---

## 🔍 Описание проблемы (Symptoms)
1. После добавления модального окна `#enroll-modal` на странице перестали срабатывать клики по ссылкам навигации, фильтрам курсов и карточкам.
2. В тёмной теме кнопка Telegram (`.button.button-outline`) становилась сплошной жёлтой вместо прозрачной контурной.
3. На мобильных устройствах с небольшой высотой экрана модальное окно выходило за границы viewport без возможности проскроллить к кнопке отправки.
4. В шапке сайта последовательность пунктов меню (`#navigation`) не соответствовала вертикальному порядку блоков на странице (блок «Цены» стоял перед «Командой» и «Клубами»).

---

## 🕵️ Причина ошибки (Root Cause)
1. **CSS Specificity vs `[hidden]`:** Селектор класса `.modal-backdrop` со стилями `position: fixed; inset: 0; z-index: 100; display: grid; opacity: 0;` переопределял встроенное браузерное правило атрибута `[hidden] { display: none; }`. Невидимый контейнер оставался в потоке с `z-index: 100` и перехватывал все `pointer-events`.
2. **Селектор темы:** Правило `[data-theme="dark"] .button` имело специфичность (0,2,0) и перезаписывало `background: #e5c06e` поверх класса `.button-outline` (0,1,0).
3. **Отсутствие ограничения высоты:** У `.modal-card` не было `max-height` и `overflow-y: auto`.
4. **Несброшенный таймер:** В `script.js` при сабмите формы запускался таймер закрытия на 3.2 секунды, который не очищался при досрочном закрытии и мог случайно закрыть повторно открытое окно.

---

## 💡 Решение (Fix)
1. В [`style.css`](../../style.css):
   - Добавлено глобальное правило `[hidden] { display: none !important; }`.
   - В `.modal-backdrop` добавлено `pointer-events: none; visibility: hidden;`, а в `.modal-backdrop.is-open` — `pointer-events: auto; visibility: visible;`.
   - Добавлено `.modal-backdrop[hidden] { display: none !important; }`.
   - В `.modal-card` добавлено `max-height: calc(100dvh - 32px); overflow-y: auto; overscroll-behavior: contain;`.
   - Исправлена специфичность кнопки: `.button.button-outline` и `[data-theme="dark"] .button.button-outline`.
   - В мобильном медиа-запросе (`<= 640px`) блок `.branch-detail` переведён в 1 колонку (`grid-template-columns: 1fr`).
2. В [`script.js`](../../script.js):
   - Внедрена очистка таймеров `modalTimer` и `submitTimer` при каждом открытии/закрытии модалки.
   - Добавлен плавный скролл к началу страницы при клике на логотип `.brand`.
3. В [`index.html`](../../index.html):
   - Скорректирован порядок ссылок меню в `#navigation` строго в соответствии с вертикальной структурой страницы.
   - На тег `<body>` добавлен `id="top"`.
