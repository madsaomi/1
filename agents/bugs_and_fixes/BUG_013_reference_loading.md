# BUG-013 — Загрузка внешних дизайн-референсов

Дата: 2026-10-27. Автор: Codex. Статус: ОГРАНИЧЕНИЕ ВНЕШНЕГО ДОСТУПА.

## Симптом
createBrowserTab для OpenLearning и Educo вернул `Timed out waiting for tab ... to navigate`, но вкладки остались открыты и затем показали доступную страницу. Inter Nation вернул `net::ERR_NAME_NOT_RESOLVED`. web.open OpenLearning/Inter Nation извлекает почти пустой текст динамической страницы.

## Причина
Отдельно различаются таймаут ожидания навигации и ошибка DNS. Пустое текстовое извлечение не доказывает пустоту визуального сайта.

## Решение
Через инвентарь/известный ID получены уже созданные публичные вкладки, без повторной навигации по тем же URL. Скриншоты OpenLearning, Cambridge, Educo просмотрены. Наблюдения Inter Nation ограничены фактическим отсутствием доступного рендера; его дизайн не оценивается по памяти. Мутации сторонних сайтов не выполнялись.

## Предотвращение
При таймауте сначала проверить состояние вкладки. Для визуальных выводов использовать изображение страницы, а не только извлеченный HTML. Не повторять DNS-сбои циклически и не смешивать их с отдельным ограничением локального file://.
