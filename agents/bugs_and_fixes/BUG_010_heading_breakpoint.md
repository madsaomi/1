# BUG-010 — Скачок размера H1 на границе мобильной верстки

Дата: 2026-10-26. Автор: Codex. Статус: РЕШЕНО В КОДЕ.

## Симптом
Из CSS следует, что H1 менялся с 47px при viewport 560px на 36px при 561px. Обнаружено независимым чтением CSS в PLAN-022; визуальный рендер не проверялся.

## Причина
Базовое `clamp(36px, 4.8vw, 58px)` и мобильное `clamp(36px, 9vw, 47px)` имели несовместимые значения на breakpoint 560px.

## Решение
В style.css оставлена единая формула `clamp(36px, calc(24px + 3vw), 58px)` без мобильного переопределения. По формуле соседние ширины 560/561px дают 40.8/40.83px. Структурная проверка и палитра проходят; изменение не затрагивает JS и контент.

## Предотвращение
Проверять граничные значения типографики по обе стороны breakpoint. Использовать одну непрерывную формулу там, где меняется только размер шрифта; отдельно проверить реальную верстку при увеличении текста.
