# BUG-002 — Дефекты общего аудита

- Дата: 2026-10-26
- Статус: ОТКРЫТО, исправления не выполнялись
- Компоненты: форма, квиз, локализация, floating island
- Обнаружил: Codex

## Симптомы и первопричины
См. agents/walkthroughs/audit_2026-10-26.md: ложное подтверждение записи без доставки, неоднозначные имена курсов, несогласованный слот, необработанный отказ localStorage, частичная локализация, влияние цели обучения на оценку знаний, доступные клавиатуре скрытые действия.

## Решение
Не применялось: пользователь запросил аудит. Рекомендации и источники приведены в отчете. Перед исправлением требуется отдельный план реализации по регламенту проекта.

## Сбои проверок
Открытие file:// отклонено браузерным инструментом: «The requested URL protocol is not allowed. Allowed protocols: http:, https:». Обход не применялся; браузерная приемка остается невыполненной. В предыдущей сессии npm отсутствовал в PATH и системный python был недоступен; текущие проверки запускаются через bundled runtime Codex.

## Предотвращение
Успех записи подтверждать по реальному результату доставки, использовать уникальные ID, тестировать деградацию настроек и пользовательские сценарии отдельно от целостности документации.
