# BUG-019 — Проверка прайса выбрала экзаменационную таблицу

Дата: 2026-10-27. Автор: Codex. Статус: ИСПРАВЛЕНО, PLAN-029.

## Симптом
Первый полный прогон новых38тестов:37pass,1fail. AssertionError: `4 !== 3` в проверке заголовков прайса.

## Причина
Новый тест искал точный class="price-table", но реальная таблица имеет2класса: "data-table price-table". Необоснованный fallback выбрал первый thead страницы — экзаменационную таблицу с4колонками. Разметка самого прайса содержала правильные3колонки.

## Решение
Тест ищет table по точному токену price-table в списке CSS-классов, затем проверяет только его thead. Fallback на чужую таблицу удален.

## Предотвращение
Проверять class как набор токенов и связывать утверждения с конкретным компонентом. Не маскировать ошибку селектора выбором первого похожего элемента.
