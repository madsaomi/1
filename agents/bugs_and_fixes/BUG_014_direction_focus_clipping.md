# BUG-014 — Обрезание клавиатурной обводки направлений

Дата: 2026-10-27. Автор: Codex. Статус: ИСПРАВЛЕНО В КОДЕ, PLAN-027.

## Симптом
Независимое чтение нового CSS выявило, что overflow:hidden у общей панели направлений обрезает внешний focus-visible ссылки на краях сетки. Глобальная обводка выступает на 4px за ссылку. Вывод по геометрии CSS; реальный браузерный рендер не наблюдался.

## Причина
После переноса направлений в общую полосу ссылки доходят до края контейнера с клиппингом радиуса, а глобальный outline-offset положительный.

## Решение
Для .hero-program:focus-visible задан outline-offset:-5px. Цвет/толщина глобального фокуса сохраняются; обводка размещается внутри ссылки. Остальные элементы и reduced motion не меняются.

## Предотвращение
При использовании overflow:hidden у интерактивного контейнера проверять крайние элементы сетки и положение фокуса. Подтвердить на клавиатуре в матрице реальной браузерной приемки.
