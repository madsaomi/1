# BUG-009 — Пустые направления оставляли строки

Дата: 2026-10-26. Автор: Codex. Статус: РЕШЕНО.

## Симптом
Новый тест renderHero([]) ожидал пустую строку, но получил три перевода строки.

## Причина
Генератор возвращал пустую строку для отсутствующей категории, после чего join добавлял разделители для всех четырех категорий.

## Решение
Фильтровать пустые элементы перед join. Пустой каталог не генерирует направления, начальные цены считаются только по существующим программам.

## Проверка
Регрессионный тест проверяет обычные цены вместо специальных, пропуск отсутствующих категорий и полностью пустой набор.
