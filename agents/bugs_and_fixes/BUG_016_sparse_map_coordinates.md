# BUG-016 — Разреженный массив проходит проверку координат

Дата: 2026-10-27. Автор: Codex. Статус: ИСПРАВЛЕНО, PLAN-028.

## Симптом
При независимом чтении новой проверки координат обнаружен случай `Array(2)`: массив длины2 без элементов мог пройти проверку, сформировав URL без числовой точки. Реальные координаты проекта плотные; дефект обнаружен до сдачи.

## Причина
`Array.prototype.every(Number.isFinite)` пропускает отсутствующие элементы, а `Math.abs(undefined) > limit` возвращает false. Длина массива сама по себе не гарантирует наличие обоих чисел.

## Решение
build.mjs проверяет Number.isFinite отдельно для индекса0 и1, затем границы долготы/широты. Тесты покрывают Array(2), массив с пропущенной широтой, NaN, Infinity, строки и выход за диапазон.

## Предотвращение
Для фиксированных кортежей валидировать каждый обязательный индекс, не полагаться только на every и length.
