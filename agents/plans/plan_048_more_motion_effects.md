## 1. 🎯 Цель
Владелец: «хочу еще эффекты» → на выбор из четырех ответил «давай всё».
1. **Первый экран по очереди:** плашка, заголовок, описание, кнопки, сноска и логотип появляются с шагом ~80 мс один раз при загрузке.
2. **Пружина:** кнопки и карточки слегка приподнимаются при наведении (с легким «перелетом») и проседают при нажатии.
3. **Переключатель цен** над каталогом: «Обычная цена / Семья · 2 курса» — цены в карточках курсов плавно пересчитываются; у курсов без семейной цены подпись «без семейной цены».
4. **Прогресс прокрутки** — тонкая желтая полоса вверху окна; **активный раздел** подсвечивается в меню.

## 2. 🔍 Решения
- Без библиотек. Все — прогрессивное улучшение: без JS/при «Уменьшить движение» сайт как сейчас.
- (1) `theme-init.js` (в `<head>`, до отрисовки) ставит `data-motion="on"`, только если движение разрешено → CSS-анимация без мигания; без JS атрибута нет.
- (2) Только CSS: `--spring` (cubic-bezier с перелетом) для transform; hover — только на устройствах с наведением; при reduced motion — без сдвигов.
- (3) `renderCourses`: у суммы `data-price`/`data-special`; переключатель — статичная разметка, видна только после `data-enhanced`; JS пересчитывает суммы (шаг по 1 000, 450 мс), при reduced motion — сразу. Без JS остаются обе цены в таблице «Стоимость обучения».
- (4) Полоса — CSS scroll-driven (`animation-timeline: scroll(root)`) на `body::before` в `@supports`; активный раздел — IntersectionObserver ставит `aria-current="location"` ссылке меню.
- Новый JS — до `countUp`/`setupReveal` (тесты вырезают эти участки). Новый видимый текст (кнопки переключателя) — в baseline каркаса с само-проверкой.
- Версии: `style.css?v=63`, `script.js?v=43`, `theme-init.js?v=37`.
