3. **Accordion** — плавное раскрытие FAQ и «Подробнее» об экзаменах.

## 2. 🔍 Решения и ограничения
- Без библиотек и зависимостей (AGENTS.md: только HTML/CSS/Vanilla JS; CSP `script-src 'self'`).
- `script.js`: новая функция `setupMotion()` **перед** `setupReveal` (тесты reveal исполняют файл с `setupReveal`). Выход сразу, если нет IntersectionObserver/requestAnimationFrame или включено «Уменьшить движение». Финальные значения — в HTML: без JS всё видно. Скрытое состояние появляется только по классу, который ставит JS.
- Stagger: CSS `animation … backwards` с задержкой `--stagger` (не transition — чтобы не перебить hover-переходы карточек); карточки видны при фокусе внутри и при переходе по якорю.
- Accordion: только CSS — `interpolate-size` + `::details-content` (Chrome/Edge 131+); в остальных браузерах как сейчас.
- Без бесконечных анимаций (тест), глобальный reduced-motion остается.
- Тексты, данные, логика фильтров/dialog/карт не меняются; `script.js?v=42`, `style.css?v=62`.
