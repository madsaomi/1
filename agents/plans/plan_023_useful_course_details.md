# PLAN-023 — Полезные карточки и полные условия курса

Дата: 2026-10-26. Автор: Codex. Статус: ВЫПОЛНЕНО В КОДЕ, ВИЗУАЛЬНАЯ ПРИЕМКА ОТКРЫТА.
Основание: пользователь просит продолжать улучшать сайт; выбран законченный проход по каталогу и окну программы.

## Подход
Короткие условия курса видны без раскрытия. Окно программы показывает обе существующие цены с условиями; для IELTS/SAT ведет к подробностям экзамена с раскрытием и передачей фокуса. Заголовок и закрытие остаются вне прокручиваемой части, открытие/смена курса сбрасывают ее прокрутку. Без новых обещаний, фактов или контактов.

## Проверка и критерии
`node build.mjs`, `node build.mjs --check`, `node --check script.js`, `node --test`, `python tests/validate_html.py`, `git diff --check`, `python agents/tools/check_integrity.py`. Условные цены не переносятся между курсами; переход закрывает dialog без возврата фокуса старому триггеру, раскрывает правильный экзамен. Каталог и прайс доступны без JS.

## Риски и откат
Структура dialog меняется: проверить ограничения высоты, прокрутку, возврат фокуса и no-JS. Сохранить обе темы, #FFB703/нейтральные, reduced motion, цены рядом, все ранее снятые разделы не возвращать. Только точечный откат затронутых фрагментов без сброса существующего рабочего дерева. Визуальная/browser-приемка не выполнена; проверки Node VM ее не заменяют.

## Результаты
25/25 тестов Node: добавлены проверки видимых условий, обеих цен и очистки прежней скидки при смене курса, внутренней прокрутки/возврата фокуса, перехода к правильному экзамену и unsupported-dialog fallback. Генерация, синтаксис JS и HTML/палитра проходят. Первый запуск нового набора выявил слишком точный тестовый regex без учета aria-label; исправлен, причина записана в BUG-011. Независимая проверка обнаружила неверный fallback на контакты: заменен переходом к прайсу с отдельным тестом. Визуальные размеры и поведение в браузере не подтверждены.
