## 1. 🎯 Цель и контекст
- **Проблема:** аудит 2026-11-04 (P1). Бесконечная карусель `#teachers` (PLAN-035) ставится на паузу только по `:hover`/`:focus-within`. На тач-устройствах без reduced motion движение нельзя остановить — нарушение WCAG 2.2.2 (Pause, Stop, Hide).
- **Решение владельца:** блок с примерными данными остается («пусть пока стоит для примера»), данные не меняются.
- **Результат:** видимый переключатель (≥44px) останавливает прокрутку и показывает всех преподавателей статичной сеткой 1/2/4 — как при reduced motion. Работает без JS (checkbox + `:has`).
- Пункт аудита P1-2 «вложенность секций» снят: при перепроверке `#clubs` закрывается на своей строке, вложенности нет (ошибка чтения вывода парсера).
