## 3. Наблюдения (не дефекты)

1. **Инструментальная особенность сессии:** первая (заявленная из file://) вкладка IAB имела «залипшую» поверхность — клики/скриншоты таймаутились; в свежей вкладке всё работало. Вкладку-дубль закрыл. На сайт не влияет; аналогично BUG-020 по классу «инструменты, не код».
2. Кнопка темы корректно исключена из проверок семантики baseline (id theme-toggle) — согласовано с design-system тестом.
3. Кэш-бастер theme-init.js?v=36 не поднимался — файл не менялся, корректно.

## 4. Ограничения аудита (честно, не закрыто этой сессией)

- **49 Node-тестов и `node build.mjs --check` не запускались** — Node/npm в среде отсутствуют. Статические контракты покрыты Python-репликацией, но прогон `npm run check` в среде с Node 22+ остаётся обязательным.
- CSP/кэш-заголовки Caddy, HTTPS ingress и Core Web Vitals — только на реальном деплое (python-сервер заголовки не воспроизводит).
- Lighthouse, screen reader, 200% zoom, полная клавиатурная навигация — не выполнялись.
- Проверка отображения вкладки/фавикона в реальном списке табов браузера владельцем (визуально).
