# Исправления по аудиту — PLAN-014

Дата: 2026-10-26. Автор: Codex.

## Что изменилось
- Фиктивные преподаватели, достижения, адреса, номера и Telegram-аккаунты сняты. Команда с вымышленными профилями удалена; вместо условной карты — честная недоступность подтвержденных адресов.
- Пользователь выбрал прямую связь. Персональные данные больше не запрашиваются: нет имени, телефона, копирования заявки и ложного успеха. Настроенные владельцем подтвержденные каналы генерируются прямо в HTML; сейчас контактов нет, запись отмечена недоступной.
- Курсы, прайс и список направлений генерируются в HTML из content.js, видны без JS. У General English и каракалпакского варианта разные стабильные ID.
- Нативный dialog вместо ручного focus trap, восстановление фокуса/прокрутки проверены в Node VM. Браузерное поведение не измерялось.
- Карусель, клоны, автоматическое движение, pointermove/blur-эффекты удалены. Светлая и темная желто-черные темы сохранены. CSS — один набор токенов и одна темная тема; увеличены мелкие тексты.
- Частичные UZ/QR переводы сняты. Полноценную локализацию нужно делать отдельными страницами после перевода.
- Кэш постоянных изображений сокращен до суток с ревалидацией; добавлена CSP self и вынесен ранний скрипт темы; внешние Google Fonts удалены. CSP/HTTPS еще требуют проверки на реальном деплое.
- Canonical и абсолютные OG генерируются при настройке реального HTTPS URL. Без домена адреса не выдумываются. robots.txt добавлен.
- CI теперь проверяет приложение, генерацию, HTML и собирает production Docker, а не только Second Brain.

- Сбои и исправления проверок: BUG-005 и BUG-006.

## Что осталось
Реальные контакты, домен, город, подтвержденные условия курсов, фотографии и квалификации команды. Без этих данных сайт не готов к платному трафику. Не подключались аналитика/CRM/бот и не создавались вымышленные отзывы или сертификаты.

Docker/Caddy отсутствуют локально; их успешный запуск не подтвержден. Браузерный file URL ранее заблокирован политикой, обход не предпринимался. Lighthouse, CWV, мобильные скриншоты, screen reader и визуальная приемка не выполнены. Тесты Node VM не подменяют браузерные.
