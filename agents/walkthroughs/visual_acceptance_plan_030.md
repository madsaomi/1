# PLAN-030 — Дизайн-система и состояние визуальной приемки

Дата: 2026-10-27. Агент: Codex. Статус: КОД ГОТОВ, BROWSER-ПРИЕМКА НЕ ВЫПОЛНЕНА.

## Реализовано
- Один mobile-first CSS вместо накопленных overrides: контейнер1200px, интервалы8px, типографика14/16/20/24/32/48/64, радиусы12/16 и единые controls48px.
- Локальный Inter variable100–900:48 256bytes Latin+18 748bytes Cyrillic, SIL OFL. font-display:swap, preload, кириллица/ASCII проверены. В production нет внешнего font-запроса или новой npm-зависимости.
- Светлая/темная тема через токены. Мелкий желтый текст на белом не используется; кнопки содержат темный текст на желтом.10новых тестов проверяют семантические пары с4.5:1 и focus3:1.
- Inline SVG заменили декоративные стрелки, плюс, тему, меню и закрытие. Иконки скрыты от accessibility tree и не фокусируются.
- Каталог2колонки от768px, последняя нечетная видимая карточка на всю ширину с учетом фильтров. Прайс375px сохраняет14px текст и обе суммы в3колонках. FAQ на широком экране — заголовок слева, список справа.
- На768px три адреса расположены над полноширинной картой, на desktop — рядом с картой; на телефоне список прокручивается внутри панели. iframe и его предки не фильтруются, не перекрашиваются и не анимируются opacity.
- Минимальные презентационные изменения script.js: удалены3textContent-присваивания иконок, их вид зависит от существующих aria-expanded/data-theme; SVG добавлен к2динамическим ссылкам; независимый setupReveal() с IntersectionObserver и safe fallback. Бизнес-логика тем/карт/меню/фильтров/dialog не менялась.

## Что подтверждено
48/48 Node tests проходят:38 прежних сценариев и10 новых проверок дизайн-системы. SHA256 content.js, Dockerfile, Caddyfile, railway.json, .dockerignore, package.json совпадает с независимым baseline. Нормализованные тексты всей страницы, ссылки, ID, alt и ARIA сохранены. Генерация актуальна; синтаксис, HTML/палитра проходят. Это не заменяет скриншоты, проверки screen reader или браузерную консоль.

## Подготовка Playwright
Запрошенный Microsoft Playwright MCP зарегистрирован через codex mcp add playwright. В PATH нет обычного npx, поэтому зарегистрированы абсолютные пути существующих Node и corepack-npx. Никакие unrestricted-file-access, browser sandbox bypass или доступ к частным профилям не добавлялись. codex mcp get подтверждает enabled/stdio; --help завершился0. В текущем ALL_TOOLS инструментов Playwright нет, нужен перезапуск Codex. Context7 не понадобился для Vanilla CSS/JS.

Ранее localfile:// был отклонен инструментом с запретом обхода. Не поднимать тот же сайт поHTTP и не открывать через инойбраузер/MCP для обхода отказа. Нужен доступ, разрешенный инструментом; новая регистрация MCP сама по себе прежний запрет не отменяет.
