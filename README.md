# Stanford Language Center

Адаптивный статический лендинг на HTML, CSS и JavaScript. Светлая и тёмная темы, каталог курсов, подсказки о скидках, автоматическая лента преподавателей и воскресные Speaking Club / Movie Club. Сборка и установка зависимостей не требуются.

## Просмотр

Откройте `index.html` в браузере. Для локального HTTP-предпросмотра можно использовать:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:4173. Python используется только как необязательный локальный сервер.

## Структура

- `index.html` — разделы страницы и тексты.
- `content.js` — программы, цены, изображения и адреса филиалов.
- `style.css` — адаптивная вёрстка, темы и анимации.
- `script.js` — интерфейс, фильтры, подсказки и лента преподавателей.
- `assets/` — используемые логотипы, изображения курсов и воскресных клубов.

## Проверки

Для проверки синтаксиса нужен Node.js. Дополнительные пакеты не используются.

```sh
npm run check
```

## Публикация

На статический хостинг нужно загрузить:

```text
index.html
content.js
style.css
script.js
assets/
```

Сайт не отправляет формы и не хранит персональные данные. Выбор темы сохраняется в браузере. Шрифт Manrope загружается из Google Fonts; запасной шрифт — Arial.

## Содержание перед запуском

Осталось указать реальные имена и фотографии преподавателей, адреса и контакты трёх филиалов, график работы и недостающие параметры программ. Карта пока является схемой-заглушкой.

Логотип предоставлен заказчиком. Предметные иллюстрации курсов и клубов созданы с помощью Imagegen и не изображают реальные помещения центра. В проекте оставлены оптимизированные JPEG-копии; исходные материалы, промпты и резервная копия предыдущей версии хранятся за пределами репозитория.

## Воскресные клубы

Speaking Club и Movie Club проходят по воскресеньям. Время и программу встреч уточняет администратор. Карточки используют изображения с фирменным логотипом Stanford из `assets/clubs/`.
