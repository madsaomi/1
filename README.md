# Stanford Language Center

Статический сайт: HTML, CSS, Vanilla JS, Caddy, Docker, Railway. Палитра интерфейса — #FFB703 и нейтральные черный/белый/серый; светлая и темная темы. По уточнению владельца встроенная карта использует естественные цвета провайдера.

## Состояние
Курсы и цены доступны в HTML без JavaScript. JavaScript добавляет фильтрацию, тему и нативный диалог программы. Фиктивные биографии, адреса и телефоны удалены. Частичные UZ/QR переводы сняты; опубликована русская версия.

Дизайн-система PLAN-030/031: один mobile-first CSS, локальный Inter variable с латиницей и кириллицей (67 004байта, лицензия в assets/fonts/OFL.txt), семантические токены обеих тем, шкала14/16/20/24/32/48/64, интервалы8px, контейнер1200px и inline SVG. Контраст текстовых пар проверяется автоматически. Scroll reveal безопасен без IntersectionObserver/JS и при reduced motion; карта не анимируется и не перекрашивается. PLAN-031 добавил непрозрачную шапку,16px списки, ритм64/96 и карточки практики. Визуальная приемка страницы еще не выполнена; актуальная матрица — в истории git (бывший agents/walkthroughs/visual_acceptance_plan_031.md). Публичные Google/Яндекс embed3филиалов проверены отдельно. В PLAN-032 исправлен только build-context blocker: .dockerignore разрешает theme-init.js/robots.txt; Dockerfile/Caddyfile/Railway сохранены.

Реальные контакты подтверждены владельцем 2026-10-27: два телефона, два Telegram для записи, отдельный HR и Instagram. Опубликованы три филиала, встроенная карта с выбором адреса и четыре внешние ссылки на карты. Формы сбора заявок, CRM и бота нет: владелец выбрал прямую связь.

## Изменение программ
1. Редактировать `content.js` (у каждой программы уникальный стабильный `id`).
2. Выполнить `npm run build` или `node build.mjs`.
3. Выполнить `npm run check`.

`build.mjs` обновляет только помеченные блоки направлений первого экрана, курсов, цен, фильтров со счетчиками, списка программ, контактов и SEO внутри `index.html`. Остальную разметку можно редактировать вручную. Генерируемые блоки вручную не редактировать. Сборка проверяет уникальность ID, цены, локальные изображения и допустимые контакты; контроль актуальности входит в CI.

## Подключение прямой связи
В `content.js` используются массивы `contacts.phones` (международные номера, плюс и цифры) и `contacts.telegrams` (прямые ссылки `https://t.me/имя_аккаунта`). `hrTelegram` и `instagram` отделены от записи. `locations` содержит id, name, address, maps с provider/google/yandex и url, необязательные `coordinates: [долгота, широта]` и `googleEmbed`. Координаты проверяются на числовые значения и географические границы; Google embed допускается только на www.google.com/maps/embed с одним непустым параметром pb, без credentials/hash. Готовый код получают через официальный Google Maps → Share → Embed a map; pb не редактировать вручную. Публикация только при `contacts.verified: true`, после подтверждения владельцем. Затем выполнить `node build.mjs`. Секреты и API-ключи не нужны.

Оба телефона и оба Telegram записи отображаются в контактах и dialog без промежуточной анкеты. HR/Instagram и карты находятся в основном контактном разделе. При verified=false все ссылки скрыты. Флаг не проверяет принадлежность аккаунта: это ответственность владельца. Один lazy iframe объединен с адресным списком: Google выбран по умолчанию, есть переключение на Яндекс. Без Google embed выбранной точки доступен Яндекс; повторный выбор не перезагружает карту. На desktop фокус остается на кнопке, на телефоне выбор адреса ведет к карте. Без JS доступны первая карта и исходные внешние ссылки. CSP разрешает iframe только https://www.google.com и https://yandex.ru; connect-src самой страницы остается none. Виджет загружает ресурсы своего провайдера.

## SEO
Когда известен production-домен, заполнить `site.url` полным HTTPS URL страницы и запустить сборку. Будут добавлены canonical, og:url и абсолютный og:image. Город Нукус и адреса/ориентир филиалов уже добавлены; источники — в истории git (бывший agents/product/contact_sources_2026-10-27.md). Полный почтовый адрес «Жазлар ораый» и LocalBusiness не выдумывать. sitemap и полноценные языковые страницы пока не создаются. robots.txt разрешает обход сайта.

## Локальный запуск
```sh
node build.mjs
python -m http.server 8080
```
Открыть http://localhost:8080. Node.js 22+ и Python 3.11+; внешних npm-зависимостей нет. Caddy-заголовки локальный Python-сервер не воспроизводит.

## Проверки
```sh
npm run check
```
Проверяются синтаксис JS, актуальность статического HTML,49тестов Node (39сценариев и10проверок дизайн-системы) и структура HTML/палитра через Python. Snapshot PLAN-030 остается неизменным; protected-тест принимает только LF/CRLF эквивалентность и2точныхдобавления .dockerignore из PLAN-032, удаление которых обязано восстановить исходный SHA256 с учетом переносов. Root COPY inputs дополнительно проверяются на наличие и default-deny allowlist контракта Docker context. Node VM проверяет контракты логики без реального браузера; эти проверки не заменяют Lighthouse, screen reader и визуальную приемку.

CI дополнительно собирает Docker, где Caddy валидирует конфигурацию. Локально Docker/Caddy в текущей среде недоступны; успешная сборка контейнера здесь не подтверждена.

## Деплой
```sh
node build.mjs
docker build -t stanford-landing .
docker run -p 8080:8080 stanford-landing
```
Healthcheck: `/healthz`. PORT по умолчанию 8080, меняется переменной окружения контейнера. Railway использует `railway.json`.

CSP разрешает только локальные скрипты/стили/изображения; внешние шрифты удалены. При подключении новых внешних ресурсов политику нужно пересмотреть. Кэш изображений ограничен сутками с ревалидацией, immutable для постоянных имен удален. HTTPS внешнего ingress нужно проверить на реальном деплое.

## Структура
- `index.html` — опубликованная страница, включая сгенерированные блоки.
- `content.js` — программы и конфигурация подтвержденных контактов.
- `build.mjs` — генерация HTML и проверка контента.
- `script.js`, `theme-init.js` — улучшения интерфейса и ранняя настройка темы.
- `style.css` — единая система токенов, компонентов и адаптивности.
- `tests/` — проверки контрактов, HTML и палитры.
- `assets/` — изображения; оригиналы сохранены, иллюстрации обесцвечиваются CSS.
- `CLAUDE.md` — правила проекта для ИИ-агентов; `tests/page_baseline.json` — эталон текста страницы (`python tests/update_baseline.py`).

## Что еще нужно перед запуском рекламы
Production-домен, реальные преподаватели/фотографии, проверка актуальности программ и цен; браузерная приемка 320/390/765/1440 px, обеих тем, клавиатуры и увеличения 200%; проверка HTTPS/CSP и Core Web Vitals на реальном HTTP(S) стенде. Контакты и результаты школы не подменять заглушками.

Прайс содержит ссылки на стабильные якоря программ. Переход раскрывает курс, скрытый фильтром; ссылку на карточку можно использовать напрямую. В диалоге есть переход обратно в каталог с корректной передачей фокуса.

Обычная и семейная/для двух курсов цена показаны вместе в строке прайса. Спеццены берутся из specialPrice; условия видны над таблицей без раскрытия. Всплывающая панель и отдельный список скидок удалены.
