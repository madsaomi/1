# Шаблон страницы

`page.html` — готовая заготовка страницы в стиле сайта: шапка, первый экран, переключатель разделов,
сетка карточек, лента при прокрутке, подвал. Стили уже лежат в `style.css`, эффекты — в `assets/ui.js`.
Писать CSS и JS заново не нужно.

## Что есть в шаблоне

| Блок | Класс или атрибут | Что делает |
| --- | --- | --- |
| Первый экран | `.results-hero` | Подпись, заголовок, абзац; на компьютере справа бейдж на ленте |
| Смена слов | `.text-loop` + `data-loop` | Слова по очереди появляются в жёлтой плашке, два круга, потом замирают |
| Счётчики | `.score-tiles` + `data-roll` | Цифры «прокручиваются» до значения, когда блок виден |
| Бейдж на ленте | `.lanyard` + `data-swing` | Качается при загрузке и слегка наклоняется за курсором (только компьютер) |
| Переключатель разделов | `.directory-nav` | Пилюли; текущая страница — `aria-current="page"` |
| Карточки | `.result-card` + `data-tilt` | Наклон к курсору и блик; на телефоне — обычная карточка |
| Лента | `.scroll-band` + `data-scroll-band` | Две строки едут навстречу друг другу только при прокрутке страницы |

Любой блок можно удалить целиком — остальные от него не зависят. Все эффекты — украшение: без JS и при
отключённых анимациях в системе страница показывает тот же текст.

## Как добавить страницу

1. Скопируйте `templates/page.html` в корень проекта, например `events.html`. Замените все «ЗАМЕНИТЬ».
2. Откройте файл в браузере через локальный сервер и проверьте 375 и 1280 px, светлую и тёмную тему.
3. Подключите страницу к сборке в `build.mjs`: добавьте функцию `generateEvents` по образцу `generateTeachers`
   (она заполняет блоки `SEO` и `ROBOTS`) и строку в список `pages`.
4. Чтобы тексты редактировались в админке, пометьте их `data-text="events.title1"` и т. п., затем выполните
   `sync_page_texts` (локально) — как описано в `cms/README.md`.
5. Добавьте русские тексты страницы в словарь узбекского через админку («Переводы на узбекский»).
6. Добавьте файл в списки: `Dockerfile` (строка `COPY`), `.dockerignore`, `tests/validate_html.py`,
   `tests/owner-workflow.test.mjs`. Правка `Dockerfile` — только с разрешения владельца.
7. Поставьте ссылку на страницу: в `.directory-nav` соседних страниц или в подвале.
8. Запустите `npm run check`.

## Правила, которые шаблон уже соблюдает

- Цвета только через CSS-переменные; размеры текста — из шкалы `--text-14 … --text-64`.
- Никаких `style="…"` и встроенных `<script>`: этого не разрешает CSP.
- Ничего не движется само бесконечно; `prefers-reduced-motion` выключает все эффекты.
- После правки `style.css`, `results.js` или `assets/ui.js` увеличьте `?v=` на страницах, где файл подключён.
