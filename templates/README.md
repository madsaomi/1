# Шаблон страницы

Карточки курсов собираются отдельно из данных админки в `build.mjs` → `renderCourses`.
Переворот включает локальный `assets/course-flip.js`: «Подробнее» открывает описание
и программу, «Назад» или Escape возвращают цену. Без JavaScript обе стороны читаются
последовательно. При добавлении курса в админке карточка появляется автоматически.

На страницах преподавателей и результатов есть два вида: «Карточки» с переворотом
и «Обычный вид» со всей информацией сразу. Используются одни данные, выбор сохраняется
в браузере. За переключатель отвечает `assets/directory-view.js`, подключённый перед
`assets/course-flip.js`. Без JavaScript показывается обычный читаемый вид.

Логотип Stanford заменяет заглушку без портрета; настоящие фото преподавателей сохраняются.
Балл студента остаётся в подробностях результата. Запланированные события добавляются
через админку и показываются со счётчиком внутри «Практики вне уроков». Если событий нет,
клубы и пробные экзамены продолжают показываться обычными карточками без таймера.

`page.html` — готовый каркас: общая шапка, короткое введение, навигация по разделам,
адаптивная сетка карточек и подвал. Используйте существующие классы из `style.css`;
отдельные CSS и JS для новой страницы не нужны.

## Единая система

| Элемент | Класс | Правило |
| --- | --- | --- |
| Ширина содержимого | `.wrap` | Общий контейнер до 1200 px |
| Раздел | `.section` | Общие вертикальные отступы, без высоты на весь экран |
| Введение | `.results-hero`, `.results-hero-copy` | Подпись, один h1 и короткий абзац |
| Навигация | `.directory-nav` | Текущая страница отмечена `aria-current="page"` |
| Карточки | `.results-grid.results-grid-page`, `.result-card` | Одна поверхность; высота определяется содержимым |
| Кнопки | `.button`, `.text-link` | Основное действие жёлтое, вспомогательное нейтральное |
| Событие | `.event-card`, `.event-countdown` | Название, дата и обратный отсчёт из админки |

Используйте шкалу отступов `--space-*`, размеров текста `--text-*` и общие цветовые
переменные. Не добавляйте внешние тени ко всем вложенным элементам, панели внутри
панелей, фоновые узоры или пустые декоративные полосы. Карточки на телефоне читаются
сверху вниз; содержимое не перелистывается само. Пустой блок не должен занимать место.

## События и обратный отсчёт

Для настоящего события откройте локальную админку `/admin/` → «События», добавьте
название, описание и дату, включите показ и нажмите «Опубликовать». Дата и время
задаются по времени Нукуса (`Asia/Tashkent`, UTC+5). В публикацию дата передаётся
в формате ISO с часовым поясом, чтобы отсчёт одинаково работал у разных посетителей.

Отсчёт работает через `assets/ui.js`: `.event-countdown` получает `data-countdown`
с датой, четыре числа — атрибуты `data-unit="days|hours|minutes|seconds"`.
Статус находится в соседнем элементе с `data-countdown-status`. Без JavaScript
посетитель всё равно видит название и дату события. Структура показана в комментарии
в `page.html` и заполняется сборщиком из данных; вручную дублировать даты не нужно.

В шаблоне нет выдуманных мероприятий, тестовых сроков и постоянно перезапускающегося
таймера. Если событий нет, их раздел не показывается. Для новой страницы подключите
`renderEvents` из `build.mjs` к её генерируемому блоку `EVENTS`.

## Как добавить страницу

1. Скопируйте `templates/page.html` в корень проекта, например `news.html`. Замените все «ЗАМЕНИТЬ».
2. Откройте файл через локальный сервер и проверьте 375 и 1280 px, светлую и тёмную тему.
3. Подключите страницу к сборке в `build.mjs`: добавьте функцию по образцу `generateTeachers`
   (она заполняет блоки `SEO` и `ROBOTS`) и строку в список `pages`.
4. Чтобы тексты редактировались в админке, пометьте их `data-text="news.title1"` и т. п., затем выполните
   `sync_page_texts` (локально) — как описано в `cms/README.md`.
5. Добавьте переводы русских текстов на узбекский и каракалпакский через админку («Переводы на узбекский и каракалпакский»).
6. Добавьте файл в списки: `Dockerfile` (строка `COPY`), `.dockerignore`, `tests/validate_html.py`,
   `tests/owner-workflow.test.mjs`, `docker/local/prepare.mjs` (обе операции копирования),
   `cms/content/github.py` (`SOURCE_FILES` и `OUTPUT_FILES`) и список страниц в
   `cms/content/serialization.py`. Это нужно для локального обновления, публикации и текстов админки.
   Правка `Dockerfile` — только с разрешения владельца.
7. Поставьте ссылку на страницу в `.directory-nav` соседних страниц или в подвале.
8. Запустите `npm run check`.

## Общие проверки

- Контент доступен без JavaScript; `prefers-reduced-motion` отключает декоративную анимацию.
- Нет горизонтального переполнения, текст и кнопки читаются в обеих темах.
- В разметке нет `style="…"` и встроенных `<script>`: этого не разрешает CSP.
- После правки `style.css`, `results.js` или `assets/ui.js` увеличьте `?v=` на страницах, где файл подключён.
