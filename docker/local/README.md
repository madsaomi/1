# Локальная копия Stanford

Из корня проекта выполните `docker compose up --build -d`.

- Сайт: http://localhost:8080 (используйте именно localhost для анкеты).
- Админка: http://localhost:8000/admin/.
- Данные входа: `.cache/docker-local/access.txt`.
- Добавьте `.cache/docker-local/admin-qr.png` в Google Authenticator.

Данные сайта импортируются при первом запуске. Изменяйте их в админке и нажимайте
«Опубликовать»: обновляется только локальный сайт. Файлы репозитория подключены
только для чтения. База, админка и HR находятся в закрытой сети; токены GitHub
и Telegram им не передаются. Анкета проверяется и собирает PDF без отправки сообщений.
Postgres, фото и опубликованные страницы сохраняются в отдельных Docker volumes.
Ручные команды CMS запускайте от пользователя приложения: например,
`docker compose exec --user app cms python manage.py audit_media`.

Остановить: `docker compose stop`. Снова запустить: `docker compose up -d`.
Посмотреть ошибки: `docker compose logs --tail=80`.
Не добавляйте `down -v`: эта опция удаляет локальные данные.

Образы и зависимости скачиваются Docker во время первой сборки. Railway и GitHub
этими командами не меняются. При пересборке обновляются шаблоны, CSS, JS и ресурсы;
данные из админки, переводы и загруженные фото сохраняются. Для отдельной новой копии используйте другое
имя Compose-проекта (`docker compose -p stanford-second up --build -d`), остановив
первую копию из-за совпадающих портов. Не используйте одну папку credentials для
нескольких копий одновременно.

На сайте доступны RU, UZ и QQ (каракалпакский, код `kaa`). Тексты и переводы редактируются
в админке. При обновлении новые переводы добавляются из словарей, а сохранённые правки
владельца остаются на месте. Для публикации изменений нажмите «Опубликовать».
